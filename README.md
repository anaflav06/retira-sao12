# RETIRADAS SAO12

Aplicativo Streamlit para cadastro e acompanhamento de cargas aguardando retirada.

## Arquivos
- `app.py` — aplicativo principal
- `requirements.txt` — dependências
- `database_retiradas_sao12.json` — banco persistente quando usado com integração GitHub

## Secrets no Streamlit
```toml
GITHUB_TOKEN = "SEU_TOKEN"
GITHUB_REPO = "anaflav06/SEU_REPOSITORIO"
GITHUB_DATA_BRANCH = "main"
GITHUB_RETIRADAS_DB_PATH = "database_retiradas_sao12.json"
```
